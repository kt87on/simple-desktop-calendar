# 简洁桌面日历

> 受够了 Windows 原生的日历，也实在受不了市面上第三方日历软件——明明很简单的需求，硬塞一堆没必要的功能。
> 自己写了这款极简日历：核心只做三件事——**看日历、看放假、看上班**，外加一个真正有用的「特别关注」提醒。
> 想要更多功能，看手机不就行了。

## ✨ 功能

> **v2.0.0 · 全套 UI 视觉重构**（只动视觉，功能/交互零改动）：建立设计 Token 体系（5 色族 + 8 字阶 + 4pt 网格）、重绘应用图标与全套单色菜单图标、黑夜模式整组补齐、退出确认弹窗 UI 化。设计规范见 [`UI_DESIGN_SYSTEM.md`](./UI_DESIGN_SYSTEM.md)。

- **极简本体**：打开就是一张日历，没有广告、没有账号、没有多余菜单。
- **任务栏挂件条（常驻）**：任务栏右端一条小窗，上行 24 小时制实时时钟（时:分）、下行年月日，不占任务栏按钮、常驻后台。
  - **左键点击** → 打开 / 隐藏日历；
  - **右键菜单** → 显示/隐藏日历、特别关注、主题、置顶、开机自启、挂件条总开关、缩小至桌面图标、退出；
  - **主窗空白处右键** → 弹出同一套菜单（兜底入口，防止挂件条被关掉后无法恢复）。
  - **v1.7.21 起两种显示形态二选一**（右键菜单「🗕 缩小至桌面图标」切换）：默认**桌面插件**（可拖动小方框）；切成**桌面图标**后插件收起，只在系统托盘留一个静态图标，左键点它再切回来。
- **贴任务栏上沿浮动（v1.7.20 起唯一形态）**：挂件条视觉上紧贴任务栏上沿右侧（116×任务栏同高，浮 8px 内缩），像原生时钟一样长时间挂着。**v1.7.13~v1.7.19 一共 7 次尝试用 `SetParent(ReBarWindow32)` 真嵌入任务栏**，每次都被 Chromium 用 `render-process-gone reason=killed` 反噬——根因是 Chromium 渲染线程在自身 HWND 被改父为 `WS_CHILD` 后做 surface tree 自检、自检失败主动 kill 自己。**v1.7.20 决策：彻底回退到浮动方案**（v1.7.11 那版从未崩过）。`dock-attach.ps1` 已废弃、`package.json` 不再打包它。
  - **v1.7.21 可拖动 + 边界限制**：按住可拖到屏幕任意位置；四条边都被夹在**屏幕工作区**内（工作区已排除任务栏），拖不出屏幕、也压不到任务栏。落点会记住，重启和从图标模式切回来都回到原处。
  - **v1.7.21 点击热区**：只有插件**可见的小方框**能响应鼠标，方框外的透明区域完全穿透、不拦截点击（此前点方框下方也能弹出日历）。
  - **v1.7.21 已删除吸附**：「自动吸附任务栏上方」和「贴回任务栏上方」两项移除——物理嵌入已放弃，这些功能没有意义且实测从未生效。
  - **v1.7.22 三处微调**：① 日历窗口与插件**间距紧贴**（1px 防撕裂，下方不够自动翻到上方紧贴）；② **今日单元格深蓝强调**（`#1565C0` 底 + 白字，只改今日一格）；③ **Win10/Win11 自动检测**（读内核 build 号写入 `isWin11` 配置项，任务栏高度仍用 `workArea` 动态获取、不硬编码）。
  - **v1.7.22.7 意图尺寸唯一真值**（修复"拖不到底 / 拖不到右 / 卡在半空"）：实测物理窗口会被引擎/OS 撑大（日志取证：请求 `116×40`，实际落到 `232×164`，且同一次运行内还会变）。此前代码拿 `dockWin.getBounds()` 的宽高去算边界，夹取出来的 `maxX/maxY` 被压缩一大截，卡片就"过不去"；同时这个错误尺寸还被 `pushDockSize()` 发给页面，卡片本身也被渲染成大块。现引入 `dockW`/`dockH` 作为唯一真值，插件定位统一走 `dockClamped(x, y)`，**任何布局/夹取都不再采信 `getBounds()` 的 width/height**（撑大出来的多出部分只是透明区，自然溢出屏幕外，无视觉影响）。
  - **v1.7.19 沿用的固定像素布局**——Chromium 在 transparent + 无边框 + 极小尺寸下首帧仍可能按 16px viewport 渲染（造成"椭圆"），主进程 `pushDockSize()` 把 `dockW`/`dockH`（意图尺寸）发给 `dock.html`，页面用固定 px 覆盖 `html`/`body`/`#card`，彻底不依赖 `height:100%` → 时钟/日期完整显示，且**完全不触碰窗口尺寸**，不引发崩溃。
- **农历 / 节气 / 节日**：每天副字显示农历、24 节气或节日名（按白名单过滤，只保留中国传统与主流民俗）。
- **放假 / 上班一目了然**：
  - 法定节假日 → 朱砂红底 + 红色「休」角标；
  - 调休补班 → 蓝色「班」角标。
- **区间天数计算**：点两个日期，端点深绿、中间浅绿连成一条带，浮层实时显示「共计 N 天」；支持跨月。
- **特别关注 / 提醒**：右键任意格子标记为「特别关注」（金黄底 +「注」角标），到日期当天自动弹窗提醒；弹窗可「知道了」（当天不再弹）或「稍后提醒」（半小时后再弹）。最多 **10 条**、每条 **15 字以内**（超出自动截断并提示）；点击工具栏的书按钮打开**独立关注列表窗口**批量查看日期/内容/一键取消，窗口可**拖到屏幕任意位置**（不再受日历窗口限制）。
- **每周起始自由切换**：周一 / 周日，一键切换，习惯你定。
- **主题白日 / 黑夜**：一键切换纸白与墨黑两套配色。
- **放大模式**：点「⊕」放大到近全屏、字号同步放大，拖到屏幕边缘自动吸附；拖拽四角可等比缩放。
- **开机自启**：安装后默认登录启动，随用随点。

## 📦 下载与安装

1. 到 [Releases](https://github.com/kt87on/simple-desktop-calendar/releases) 下载 `简洁桌面日历 Setup 2.0.0.exe`。
2. 双击运行，按向导「下一步 → 完成」即可。
   - 默认安装到当前用户目录（无需管理员权限）；也可点「浏览」改路径。
   - 默认勾选「创建桌面快捷方式」与「开始菜单快捷方式」。
3. 安装完成后可勾选「立即运行」与「查看说明文档」。

> 卸载：控制面板 → 程序和功能 → 简洁桌面日历 → 卸载；或开始菜单文件夹内的「卸载」。

## 🖱️ 使用

- **任务栏挂件条**：任务栏右端实时时钟（时:分 + 年/月/日），左键打开/隐藏日历；点界面外任意处自动隐藏。
- **翻月**：左上「‹ ›」箭头，或下拉选择年/月，点「今」回到本月。
- **算天数**：依次点两个日期 → 显示「共计 N 天」（端点深绿、中间更浅的绿连成一条带；v1.7.12 提亮中间色，v1.7.13 修复「放大模式下中间不变绿」）；第三下点击或按 `Esc`、点空白处取消。
- **特别关注**：右键某个日期 → 输入框填写备忘（**15 字以内**）→ 确认后该格变金黄；到日期当天自动弹窗提醒。最多 10 条，满了会提示先取消一条。
  - **快速浏览**：鼠标直接指向格子右上角的「注」小标注，即可看到完整内容（原「悬停 2 秒气泡」已在 v1.7.11 移除）。
  - **批量管理**：点工具栏的书图标按钮，打开**独立关注列表窗口**（「日期 / 内容 / ✕」三列），内容列已加宽、几乎不透明可清晰阅读；内容过长可**按住左右拖**；✕ 一键取消该日关注。
  - **拖动窗口**：关注列表是独立窗口，按住顶部「关注列表」标题栏即可把它拖到**屏幕任意位置**（不再局限在日历窗口内），位置会记住；✕ 或 `Esc` 关闭。
  - 右键菜单「特别关注」展开为二级菜单，一级显示概览，二级列出全部可点击跳转（v1.7.20 起「查看/管理」与「查看/跳转」已合并为一项）。
- **放大**：点右上「⊕」放大；放大态拖到屏幕边缘自动吸附，拖拽四角可等比缩放；点别处退出放大。
- **每周起始 / 主题**：右上「一/日」开关与「☾」主题按钮（白日 ↔ 黑夜）。

## 🛠 技术栈

- [Electron](https://www.electronjs.org/) 31（桌面壳，系统托盘 + 无边框透明窗口 + 独立提醒弹窗）
- [electron-builder](https://www.electron.build/) 24（NSIS 安装包）
- 纯前端：HTML + CSS（`color-mix` 主题派生）+ 原生 JS，零运行时依赖
- 农历数据：[lunar.min.js](https://github.com/6tail/lunar-javascript)（第三方库，仅读取不修改）
- 特别关注持久化：`userData/reminders.json`（主进程原子读写，60s 巡检触发提醒弹窗）

## 🧑‍💻 本地开发 / 打包

```bash
cd 简洁桌面日历        # 进入项目目录
npm install            # 首次安装 Electron 等依赖（仅打包/运行桌面端需要）
npm run dev            # 开发预览：Electron 弹出桌面日历
npm run build          # 打包：在 dist/ 生成 简洁桌面日历 Setup 1.7.13.exe
```

> 无需打包时，可直接双击 `calendar.html` 在浏览器预览界面（不含托盘/提醒弹窗/吸附等桌面特性）。

## ⚠️ 已知限制

- **节假日数据为 2026 年硬编码**（国务院办公厅安排）。每年需更新 `app.js` 中的 `HOLIDAYS_2026`（放假区间）与补班 `WK`，以及 `holidays.js` 的节日列表。后续版本计划改为内置多年份数据或联网更新。
- 仅支持 **Windows**（依赖系统托盘与窗口特性）。
- 农历库为第三方库，仅读取其 `Solar` / `Lunar` 接口。
