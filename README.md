# 简洁桌面日历

> 受够了 Windows 原生的日历，也实在受不了市面上第三方日历软件——明明很简单的需求，硬塞一堆没必要的功能。
> 自己写了这款极简日历：**什么功能都没有，核心只做一件事——看日历、看放假、看上班，就够了。**
> 想要更多功能，看手机不就行了。

## ✨ 功能

- **极简本体**：打开就是一张日历，没有广告、没有账号、没有多余菜单。
- **实时时钟**：任务栏托盘常驻一个实时时钟（时:分 + 月-日），悬停显示农历与星期。
- **农历 / 节气 / 节日**：每天副字显示农历、24 节气或节日名（按白名单过滤，只保留中国传统与主流民俗）。
- **放假 / 上班一目了然**：
  - 法定节假日 → 朱砂红底 + 红色「休」角标；
  - 调休补班 → 蓝色「班」角标。
- **每周起始自由切换**：周一 / 周日，一键切换，习惯你定。
- **主题跟随系统**：默认雅蓝主题，可一键切换为跟随 Windows 强调色。
- **放大模式**：点「⊕」放大到近全屏，方便老花眼或远距离查看；拖到屏幕边缘自动吸附。
- **开机自启**：安装后默认登录启动，托盘常驻，随用随点。

## 📦 下载与安装

1. 到 [Releases](https://github.com/YG/simple-desktop-calendar/releases) 下载 `简洁桌面日历 Setup 1.0.0.exe`。
2. 双击运行，按向导「下一步 → 完成」即可。
   - 默认安装到当前用户目录（无需管理员权限）；也可点「浏览」改路径。
   - 默认勾选「创建桌面快捷方式」与「开始菜单快捷方式」。
3. 安装完成后可勾选「立即运行」与「查看说明文档」。

> 卸载：控制面板 → 程序和功能 → 简洁桌面日历 → 卸载；或开始菜单文件夹内的「卸载」。

## 🖱️ 使用

- **托盘时钟**：右下角任务栏出现实时时钟图标，点击打开/隐藏日历，点界面外任意处自动隐藏。
- **翻月**：左上「‹ ›」箭头，或下拉选择年/月，点「今」回到本月。
- **放大**：点右上「⊕」放大；放大态拖到屏幕边缘自动吸附；点别处退出放大。
- **每周起始 / 主题**：右上「一/日」开关与「☾」主题按钮。

## 🛠 技术栈

- [Electron](https://www.electronjs.org/) 31（桌面壳，系统托盘 + 无边框透明窗口）
- [electron-builder](https://www.electron.build/) 24（NSIS 安装包）
- 纯前端：HTML + CSS（`color-mix` 主题派生）+ 原生 JS
- 农历数据：[lunar.min.js](https://github.com/6tail/lunar-javascript)（第三方库，仅读取不修改）

## 🧑‍💻 本地开发 / 打包

```bash
cd 3.0                 # 进入项目目录
npm install            # 首次安装 Electron 等依赖（仅打包/运行桌面端需要）
npm run dev            # 开发预览：Electron 弹出桌面日历
npm run build          # 打包：在 dist/ 生成 简洁桌面日历 Setup 1.0.0.exe
```

> 无需打包时，可直接双击 `calendar.html` 在浏览器预览界面（不含托盘/吸附等桌面特性）。

### 目录结构

```
3.0/
├── template.html      # 界面模板（设计系统：纸与光）
├── app.js             # 渲染逻辑：日历/农历/节假日/灯效/双窗口
├── electron-main.js   # 主进程：系统托盘时钟 / 双窗口 / IPC
├── preload.js         # 安全的渲染↔主进程桥接
├── lunar.min.js       # 第三方农历库（不修改）
├── build.js           # 把 lunar+app 注入模板，生成 calendar.html
├── calendar.html      # 构建产物（可直接浏览器打开预览）
├── make-icon.js       # 生成 icon.ico（蓝磁贴+白日历卡）
├── icon.ico           # 多尺寸图标（exe/安装包/快捷方式共用）
├── installer.nsh      # NSIS 完成页扩展（查看说明文档）
├── 使用说明.html      # 安装后"查看文档"打开的帮助页
├── README.md          # 本文件（GitHub 说明）
└── package.json       # 版本/作者/NSIS 打包配置
```

## ⚠️ 已知限制

- **节假日数据为 2026 年硬编码**（国务院办公厅安排）。每年需更新 `app.js` 中的 `HOLIDAYS_2026`（放假区间）与补班 `WK`。后续版本计划改为内置多年份数据或联网更新。
- 仅支持 **Windows**（依赖系统托盘与窗口特性）。
- 农历库为第三方库，仅读取其 `Solar` / `Lunar` 接口。
