# 简洁桌面日历

> 受够了 Windows 原生的日历，也实在受不了市面上第三方日历软件——明明很简单的需求，硬塞一堆没必要的功能。
> 自己写了这款极简日历：核心只做三件事——**看日历、看放假、看上班**，外加一个真正有用的「特别关注」提醒。
> 想要更多功能，看手机不就行了。

## ✨ 功能

- **极简本体**：打开就是一张日历，没有广告、没有账号、没有多余菜单。
- **任务栏挂件条（常驻）**：任务栏右端一条小窗，上行 24 小时制实时时钟（时:分:秒），下行星期与日期，不占任务栏按钮、常驻后台。
  - **左键点击** → 打开 / 隐藏日历；
  - **右键菜单** → 本年最近节日、特别关注、显示/隐藏日历、设置、退出软件；
  - **主窗空白处右键** → 弹出同一套菜单（兜底入口，防止挂件条被关掉后无法恢复）。
  - **可拖动 + 边界限制**：按住可拖到屏幕任意位置；四条边都被夹在**屏幕工作区**内（工作区已排除任务栏），拖不出屏幕、也压不到任务栏；落点会记住，重启回到原处。
  - **多屏记忆（v2.4.0）**：外接屏断连后插件会回落到存活屏，重新连接后自动还原到原屏原位。
  - **点击热区**：只有插件**可见的小方框**能响应鼠标，方框外的透明区域完全穿透、不拦截点击。
- **农历 / 节气 / 节日**：每天副字显示农历、24 节气或节日名（按白名单过滤，只保留中国传统与主流民俗）。
- **放假 / 上班一目了然**：
  - 法定节假日 → 朱砂红底 + 红色「休」角标；
  - 调休补班 → 蓝色「班」角标。
- **区间天数计算**：点两个日期，端点深绿、中间浅绿连成一条带，浮层实时显示「共计 N 天」；支持跨月；第三下点击或点窗口外取消。
- **特别关注 / 提醒**：右键任意格子标记为「特别关注」（金黄底 +「注」角标），**可选填定时（时:分）**——填了就在当天该时刻提醒，留空则当天首次打开时提醒；添加面板会实时显示「定时提醒：H时M分」。弹窗可「知道了」（当天不再弹）或「稍后提醒」（半小时后再弹）。每条 **15 字以内**；点击工具栏的书按钮打开**独立关注列表窗口**，窗口按 **日期 / 关注内容 / 定时 / 删除** 四列展示，**并可直接在窗口底部「＋ 新增关注」录入**（不必回到日历逐个点击），添加后日历界面自动同步；窗口可拖到屏幕任意位置并记住位置。
- **每周起始自由切换**：周一 / 周日，一键切换，习惯你定。
- **皮肤系统（v3.1.0）**：设置里点「🎨 皮肤设置」打开**独立皮肤设置窗口**。主视图是 **6 行原生风格列表**，点一行即应用到全部界面；需要导入图片或细调时，点末行「**自选图片**」在浮层里设置：
  - **风格（6 种材质）**：默认 / 极简 / 玻璃拟态 / 新拟态 / 科技感 / 温润拟物。原生风格**固定不可调**，但每套都做了针对性设计——**科技感是赛博朋克**（青 + 品红双霓虹、网格、切角），**玻璃拟态是磨砂玻璃**（自绘光斑 + 斜向光泽带）；
  - **背景来源**：原生 或 自选图片（**可与风格叠加**，如「玻璃拟态 + 自选图片」）；
  - **明暗**：自动（跟随风格）/ 浅色 / 深色 / 跟随系统（实时跟随系统深浅色）；
  - **原生风格默认「四处统一」**：日历 / 放大界面 / 桌面插件 / 浮动插件默认一致；**若你单独调整过某个界面，该界面会自动转为独立、不再跟随**（也可手动切回「跟随主界面」）；
  - **自选图片**：拖拽导入、拖动取景、滚轮缩放（1×~5×）、GIF 动图、图片不透明度（20%~100%）；取景框随界面比例不同；图片自动复制进数据目录，删原文件不影响；
  - **文字明暗**：自动 / 深字 / 浅字——**只改文字、不改整窗明暗**；
  - **UI 清晰度**：可按背景复杂度自动推导，也可手动调保护强度。
- **v3.1.0 要点**：皮肤窗精简为 6 行风格列表（细调移入「自选图片」浮层）；六套原生风格视觉重做；原生风格默认四处统一、手调后自动独立；特别关注支持定时与列表内直接录入；修复升级后浮动插件自定义配置被静默忽略、手动调整被静默忽略、提醒弹窗被置顶主窗遮挡、深色档上下月日期几乎不可见。
- **放大模式**：点「⊕」放大到近全屏、字号同步放大，拖到屏幕边缘自动吸附；拖拽四角可等比缩放。
- **开机自启**：安装后默认登录启动，随用随点。

## 📦 下载与安装

1. 到 [Releases](https://github.com/kt87on/simple-desktop-calendar/releases) 下载 `SimpleCalendar-Setup-3.1.0.exe`。
2. 双击运行，按向导「下一步 → 完成」即可。
   - 默认安装到当前用户目录（无需管理员权限）；也可点「浏览」改路径。
   - 默认勾选「创建桌面快捷方式」与「开始菜单快捷方式」。
3. 安装完成后可勾选「立即运行」与「查看说明文档」。

> 卸载：控制面板 → 程序和功能 → 简洁桌面日历 → 卸载；或开始菜单文件夹内的「卸载」。

## 🖱️ 使用

- **任务栏挂件条**：任务栏右端实时时钟（时:分:秒 + 星期/日期），左键打开/隐藏日历；点界面外任意处自动隐藏。
- **翻月**：左上「‹ ›」箭头，或下拉选择年/月，点「今」回到本月。
- **算天数**：依次点两个日期 → 显示「共计 N 天」（端点深绿、中间更浅的绿连成一条带）；第三下点击或按 `Esc`、点空白处取消。
- **特别关注**：右键某个日期 → 输入框填写备忘（**15 字以内**）→ 确认后该格变金黄；到日期当天自动弹窗提醒。
  - **快速浏览**：鼠标指向格子右上角的「注」小标注即可看到完整内容。
  - **批量管理**：点工具栏书图标按钮打开独立关注列表窗口（日期 / 内容 / ✕ 三列）。
- **皮肤设置**：设置 →「🎨 皮肤设置」→ 选界面（日历/放大/桌面/浮动）→ 调「风格（6 种）」「背景来源（原生/自选图片）」「明暗（自动/浅色/深色/跟随系统）」，另有「文字明暗」「UI 清晰度」与「透明度」。
- **放大**：点右上「⊕」放大；放大态拖到屏幕边缘自动吸附，拖拽四角可等比缩放；点别处退出放大。
- **每周起始**：右上「一/日」开关切换周一 / 周日起始。主题 / 明暗请在「设置 → 皮肤设置」中调整（v3 起主窗不再有 ☾/☀ 按钮）。

## 🛠 技术栈

- [Electron](https://www.electronjs.org/) 31（桌面壳，系统托盘 + 无边框透明窗口 + 独立提醒弹窗）
- [electron-builder](https://www.electron.build/) 24（NSIS 安装包）
- 纯前端：HTML + CSS（`color-mix` 主题派生 + CSS 变量皮肤层）+ 原生 JS，零运行时依赖
- 农历数据：[lunar.min.js](https://github.com/6tail/lunar-javascript)（第三方库，仅读取不修改）
- 图片皮肤：自定义特权协议 `skin://` 加载用户数据目录下的本地图片，主进程 `nativeImage` 采样亮度判定文字明暗

## 🧑‍💻 本地开发 / 打包

```bash
cd 简洁桌面日历        # 进入项目目录
npm install            # 首次安装 Electron 等依赖（仅打包/运行桌面端需要）
npm run dev            # 开发预览：Electron 弹出桌面日历
npm run build          # 打包：在 dist/ 生成 SimpleCalendar-Setup-3.1.0.exe
```

> 闸门链：`npm run check`（= verify + smoke + runtime + qa-v244 + qa-v300 + qa-v310）与 `npm run prebuild` 同源，打包前自动跑。

> 无需打包时，可直接双击 `calendar.html` 在浏览器预览界面（不含托盘/提醒弹窗/吸附等桌面特性）。

## ⚠️ 已知限制

- **节假日数据为 2026 年硬编码**（国务院办公厅安排）。每年需更新 `app.js` 中的 `HOLIDAYS_2026`（放假区间）与补班 `WK`，以及 `holidays.js` 的节日列表。
- 仅支持 **Windows**（依赖系统托盘与窗口特性）。
- 农历库为第三方库，仅读取其 `Solar` / `Lunar` 接口。
- 图片皮肤无尺寸/像素上限（按用户意愿不设限），超大图片会占用较多内存；GIF 动图在窗口隐藏时仍保持播放。
