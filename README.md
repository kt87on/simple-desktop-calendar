# 简洁桌面日历

> 受够了 Windows 原生的日历，也实在受不了市面上第三方日历软件——明明很简单的需求，硬塞一堆没必要的功能。
> 自己写了这款极简日历：核心只做三件事——**看日历、看放假、看上班**，外加一个真正有用的「特别关注」提醒。
> 想要更多功能，看手机不就行了。

## ✨ 功能

- **极简本体**：打开就是一张日历，没有广告、没有账号、没有多余菜单。
- **任务栏挂件条（常驻）**：任务栏右端一条小窗，上行 24 小时制实时时钟（时:分），下行年月日，不占任务栏按钮、常驻后台。
  - **左键点击** → 打开 / 隐藏日历；
  - **右键菜单** → 显示/隐藏日历、特别关注、主题、置顶、开机自启、挂件条总开关、缩小至桌面图标、退出；
  - **主窗空白处右键** → 弹出同一套菜单（兜底入口，防止挂件条被关掉后无法恢复）。
  - **可拖动 + 边界限制**：按住可拖到屏幕任意位置；四条边都被夹在**屏幕工作区**内（工作区已排除任务栏），拖不出屏幕、也压不到任务栏；落点会记住，重启回到原处。
  - **多屏记忆（v2.4.0）**：外接屏断连后插件会回落到存活屏，重新连接后自动还原到原屏原位。
  - **点击热区**：只有插件**可见的小方框**能响应鼠标，方框外的透明区域完全穿透、不拦截点击。
- **农历 / 节气 / 节日**：每天副字显示农历、24 节气或节日名（按白名单过滤，只保留中国传统与主流民俗）。
- **放假 / 上班一目了然**：
  - 法定节假日 → 朱砂红底 + 红色「休」角标；
  - 调休补班 → 蓝色「班」角标。
- **区间天数计算**：点两个日期，端点深绿、中间浅绿连成一条带，浮层实时显示「共计 N 天」；支持跨月；第三下点击或点窗口外取消。
- **特别关注 / 提醒**：右键任意格子标记为「特别关注」（金黄底 +「注」角标），到日期当天自动弹窗提醒；弹窗可「知道了」（当天不再弹）或「稍后提醒」（半小时后再弹）。最多 **10 条**、每条 **15 字以内**；点击工具栏的书按钮打开**独立关注列表窗口**批量查看日期/内容/一键取消，窗口可拖到屏幕任意位置。
- **每周起始自由切换**：周一 / 周日，一键切换，习惯你定。
- **皮肤系统（v2.4.0）**：设置里点「皮肤设置」打开**独立皮肤设置窗口**，按「日历 / 放大 / 桌面插件 / 浮动插件」4 个界面分别设置皮肤：
  - 每界面支持 **白天 / 黑夜 / 跟随系统 / 纯色 / 自选图片** 5 种皮肤；
  - **桌面插件、放大界面默认跟随日历**（可取消勾选单独设置），**浮动插件独立**；
  - **纯色**：预设色板 + 原生取色器，文字自动明暗（深底浅字 / 浅底深字）；
  - **自选图片**：拖拽导入、拖动取景、滚轮缩放、GIF 动图、图片不透明度调节（20%~100%）；取景框随界面比例不同；图片自动复制进数据目录，删原文件不影响；
  - **文字描边**：图片/纯色皮肤下文字自动加一圈反向描边（深底白字配深描边、浅底黑字配浅描边），局部亮暗不均也能看清；
  - **跟随系统**：随系统深浅色实时切换。
- **主题白日 / 黑夜**：原生皮肤一键切换纸白与墨黑两套配色。
- **放大模式**：点「⊕」放大到近全屏、字号同步放大，拖到屏幕边缘自动吸附；拖拽四角可等比缩放。
- **开机自启**：安装后默认登录启动，随用随点。

## 📦 下载与安装

1. 到 [Releases](https://github.com/kt87on/simple-desktop-calendar/releases) 下载 `SimpleCalendar-Setup-2.4.0.exe`。
2. 双击运行，按向导「下一步 → 完成」即可。
   - 默认安装到当前用户目录（无需管理员权限）；也可点「浏览」改路径。
   - 默认勾选「创建桌面快捷方式」与「开始菜单快捷方式」。
3. 安装完成后可勾选「立即运行」与「查看说明文档」。

> 卸载：控制面板 → 程序和功能 → 简洁桌面日历 → 卸载；或开始菜单文件夹内的「卸载」。

## 🖱️ 使用

- **任务栏挂件条**：任务栏右端实时时钟（时:分 + 年/月/日），左键打开/隐藏日历；点界面外任意处自动隐藏。
- **翻月**：左上「‹ ›」箭头，或下拉选择年/月，点「今」回到本月。
- **算天数**：依次点两个日期 → 显示「共计 N 天」（端点深绿、中间更浅的绿连成一条带）；第三下点击或按 `Esc`、点空白处取消。
- **特别关注**：右键某个日期 → 输入框填写备忘（**15 字以内**）→ 确认后该格变金黄；到日期当天自动弹窗提醒。
  - **快速浏览**：鼠标指向格子右上角的「注」小标注即可看到完整内容。
  - **批量管理**：点工具栏书图标按钮打开独立关注列表窗口（日期 / 内容 / ✕ 三列）。
- **皮肤设置**：设置 → 「皮肤设置」→ 选界面（日历/放大/桌面/浮动）→ 选皮肤类型（白天/黑夜/跟随系统/纯色/自选图片）+ 调透明度。
- **放大**：点右上「⊕」放大；放大态拖到屏幕边缘自动吸附，拖拽四角可等比缩放；点别处退出放大。
- **每周起始 / 主题**：右上「一/日」开关与「☾」主题按钮（白日 ↔ 黑夜）。

## 🛠 技术栈

- [Electron](https://www.electronjs.org/) 31（桌面壳，系统托盘 + 无边框透明窗口 + 独立提醒弹窗）
- [electron-builder](https://www.electron.build/) 24（NSIS 安装包）
- 纯前端：HTML + CSS（`color-mix` 主题派生 + CSS 变量皮肤层）+ 原生 JS，零运行时依赖
- 农历数据：[lunar.min.js](https://github.com/6tail/lunar-javascript)（第三方库，仅读取不修改）
- 图片皮肤：自定义特权协议 `skin://` 加载用户数据目录下的本地图片，主进程 `nativeImage` 采样亮度判定文字明暗

## 🧑‍💻 本地开发 / 打包

```bash
cd 简洁桌面日历        # 进入项目目录
npm install            # 首次安装 Electron 等依赖（仅打包/运行桌面端需要）
npm run dev            # 开发预览：Electron 弹出桌面日历
npm run build          # 打包：在 dist/ 生成 简洁桌面日历 Setup 2.4.0.exe
```

> 无需打包时，可直接双击 `calendar.html` 在浏览器预览界面（不含托盘/提醒弹窗/吸附等桌面特性）。

## ⚠️ 已知限制

- **节假日数据为 2026 年硬编码**（国务院办公厅安排）。每年需更新 `app.js` 中的 `HOLIDAYS_2026`（放假区间）与补班 `WK`，以及 `holidays.js` 的节日列表。
- 仅支持 **Windows**（依赖系统托盘与窗口特性）。
- 农历库为第三方库，仅读取其 `Solar` / `Lunar` 接口。
- 图片皮肤无尺寸/像素上限（按用户意愿不设限），超大图片会占用较多内存；GIF 动图在窗口隐藏时仍保持播放。
