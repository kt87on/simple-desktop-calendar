简洁桌面日历

极简 Windows 桌面日历 —— 看日历、看放假、看上班，就这三件事。
当前版本 v2.4.0

一、软件介绍

简洁桌面日历是一款 Windows 桌面日历软件。它常驻在任务栏右端显示实时时钟，点一下就能唤出一张无边框的漂亮日历，点界面外任意处即可收起，随点随用、不打扰桌面。

  • 极简：无广告、无账号、无云同步，也没有待办、天气等多余功能。
  • 任务栏实时时钟：任务栏右端常驻「时:分:秒 + 星期/日期」，像原生时钟一样长在任务栏上。
  • 放假 / 上班一目了然：法定节假日标红「休」，调休补班标蓝「班」。
  • 农历 / 节日 / 节气：每天格子下方自动显示农历、传统节日或 24 节气。
  • 区间算天数：点两个日期，自动算出「共计 N 天」，支持跨月。
  • 特别关注提醒：给重要日期做记号，到期当天自动弹窗提醒。
  • 白日 / 黑夜双主题：一键切换，护眼协调。
  • 皮肤系统：日历、放大、桌面插件、浮动插件四个界面可分别设置「浅色 / 深色 / 跟随系统 / 纯色 / 图片」五种皮肤，配色自由。
  • 自定义图片背景：可为日历或插件设置本地图片背景（支持 PNG / JPG / GIF 动图 / WebP），文字自动适配明暗。

二、安装与启动

安装

  1. 下载 简洁桌面日历 Setup x.x.x.exe 安装包。
  2. 双击运行，按向导「下一步 → 完成」即可。
  3. 安装完成后，可勾选「运行软件」与「查看说明文档」。
默认会创建桌面快捷方式和开始菜单快捷方式，并设置为开机自启（可在设置中关闭）。

卸载

开始菜单 →「卸载简洁桌面日历」，或在「控制面板 → 程序和功能」中选择卸载即可。

三、功能说明

1. 任务栏挂件条（浮动时钟）

任务栏右端常驻一个小方框，显示当前时间（含秒）与星期、日期。它有多种用法：

  • 点一下：打开 / 关闭日历主窗口。
  • 按住拖动：把它移到屏幕任意位置（不会拖出屏幕、也不会压住任务栏），位置会被记住。
  • 右键：弹出功能菜单（最近节日、特别关注、显示/隐藏日历、设置、退出软件）。

2. 日历主窗口

  • 翻月：「‹ ›」箭头翻上 / 下月；年、月下拉框直接跳到任意年/月；「今」一键回到当前月。
  • 看日期：每格显示阳历数字 + 农历/节日/节气小字。
  • 放假 / 上班：法定节假日红底标「休」，调休补班标「班」。
  • 区间算天数：点第一个日期，再点第二个日期，中间连成色带并显示「共计 N 天」。
  • 放大模式：点放大镜「+」近全屏放大，字号、间距同步变大；可拖动窗口，拖四角可等比缩放。
  • 主题切换：点「☾ / ☀」在白日 / 黑夜两套配色间切换。

3. 特别关注（到期提醒）

  • 添加：右键某个日期 → 输入备忘（15 字以内）→ 确认，该格变金黄底「注」角标。
  • 提醒：到日期当天自动弹出提醒窗口，「知道了」当天不再弹，「稍后提醒」30 分钟后再弹。
  • 管理：点工具栏的书图标，打开关注列表窗口批量查看、一键取消。

4. 桌面插件

在「设置」中开启「桌面插件」，即可把日历板块（不含顶部时间条）作为一块桌面工具摆在桌面上，像 Windows 桌面小工具一样：

  • 拖动：按住可移到任意位置（屏幕边框与任务栏为界）。
  • 锁定：点锁定键后固定位置，不再被误拖；其余功能照常使用。

5. 设置

右键菜单 →「设置」打开设置弹窗（可拖动窗口），集中管理：

  • 主题：白日 / 黑夜。
  • 窗口行为：日历窗口置顶、开机自启、挂件条总开关、插件置顶。
  • 显示形态：浮动插件 / 托盘图标。
  • 桌面插件：开关桌面工具。
  • 窗口透明度：分别调节浮动插件、日历、桌面插件的透明度。
  • 皮肤：为日历、放大、桌面插件、浮动插件分别选择「浅色 / 深色 / 跟随系统 / 纯色 / 图片」皮肤，可自定义颜色或导入本地图片。
  • 数据：手动检查节假日更新。

6. 节假日自动更新

软件会联网检查最新的放假安排，有新数据时自动弹出确认窗口：更新成功显示明细，失败会提示原因。也可在设置中随时手动检查。

五、常见问题

  • 挂件条不见了？—— 右键日历空白处 →「设置」里重新打开挂件条，或把显示形态切回「插件」。
  • 日历点不出来 / 点别处不消失？—— 挂件条只有小方框内响应鼠标，方框外是故意穿透的，请点方框本体。
  • 拖挂件条时卡在半空？—— 拖动受屏幕工作区限制，属正常；异常时重启软件即恢复默认位置。
  • 节假日数据准吗？—— 节假日来自联网更新的官方安排，会在每年发布后自动更新，也可手动检查。
  • 怎么关闭开机自启？—— 右键菜单 →「设置」里取消「开机自启」即可。
