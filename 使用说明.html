简洁桌面日历 · 软件介绍与使用说明书

极简 Windows 桌面日历　v2.0.0　作者：YG

受够了 Windows 原生日历，也实在受不了满屏广告、账号、会员的第三方日历？这款极简桌面日历，打开就是一张日历，只做三件事——看日历、看放假、看上班，外加一个真正有用的「特别关注」到期提醒。

一、软件介绍

简洁桌面日历常驻在任务栏右端显示实时时钟，点击即唤出一张无边框的漂亮日历，随点随用、点外即隐。

  • 极简：无广告、无账号、无云同步、无待办/天气等多余功能。
  • 任务栏实时时钟：像原生时钟一样长在任务栏上，不占任务栏按钮。
  • 放假/上班一目了然：法定节假日标 休、调休补班标 班。
  • 农历/节日/节气：每天副字显示农历、节日或 24 节气。
  • 区间算天数：点两个日期自动算「共计 N 天」，支持跨月。
  • 特别关注提醒：重要日期标金黄 注，到期当天自动弹窗提醒。
  • 白日/黑夜双主题：一键切换，护眼协调。
  • 放大模式：点「⊕」近全屏放大，字号同步变大。

二、安装与启动

系统要求

Windows 10（build 19045+）或 Windows 11，无需管理员权限。

安装步骤

  • 从 GitHub Releases 下载 简洁桌面日历 Setup x.x.x.exe。
  • 双击运行，按向导「下一步 → 完成」。
  • 默认创建桌面/开始菜单快捷方式，并设置开机自启。
卸载：控制面板 → 程序和功能 → 简洁桌面日历 → 卸载。

三、界面说明

  • 信息条：左侧大号实时时钟，右侧日期 + 农历。
  • 功能栏：年/月下拉、「‹ ›」翻月、「今」回今天、「一/日」周起始、主题、「⊕」放大。
  • 日历网格：7 列日期，每格显示阳历数字 + 农历/节日副字。

四、功能使用说明

4.1 打开 / 隐藏日历

左键点任务栏右端时钟挂件条打开；点日历界面外任意处自动隐藏。

4.2 任务栏挂件条

任务栏右端实时时钟常驻显示，两种形态（右键菜单切换）：

  • 桌面插件（默认）：可拖动小方框，按住拖到屏幕任意位置（不越界、不压任务栏），落点记住。
  • 桌面图标：收起插件，只在系统托盘留静态图标，左键点它切回。
挂件条右键、或日历主体空白处右键，都能弹出功能菜单（主题 / 置顶 / 开机自启 / 挂件条开关 / 双形态切换 / 退出等）。

4.3 翻月 / 回到今天

「‹ ›」翻月；年、月下拉框跳转；「今」回当前月。

4.4 农历 / 节日 / 节气

每格副字自动显示农历（如「廿五」）、节日（如「中秋」）或 24 节气（如「白露」）。

4.5 放假 / 上班

法定节假日 休 红底；调休补班 班 蓝角标。

4.6 区间天数计算

依次点两个日期 → 两端深绿、中间浅绿连成色带，浮层显示「共计 N 天」；第三次点击、Esc 或点空白取消。支持跨月。

4.7 特别关注 / 提醒

  • 右键日期 → 输入备忘（15 字内）→ 该格变金黄 注。
  • 到期当天自动弹窗：知道了（当天不再弹）/ 稍后提醒（30 分钟后再弹）。
  • 鼠标指向「注」小标可快速预览；点工具栏书图标打开关注列表窗口批量管理（可拖到任意位置）。
  • 最多 10 条、每条 15 字内。

4.8 每周起始切换

点「一 / 日」开关，选择每周从周一还是周日开始。

4.9 主题（白日 / 黑夜）

点「☾ / ☀」按钮在纸白与墨黑间切换，选择被记住。

4.10 放大模式

点「⊕」放大；放大态拖到屏幕边缘自动吸附、四角可等比缩放；点界外退出。

4.11 退出软件

挂件条右键 → 「退出软件」，弹出确认卡片 → 点「退出」才真正退出；「取消」或 Esc 留在原处。

五、常见问题（FAQ）

  • 挂件条不见了？ 右键日历空白处 → 菜单重开挂件条；或从「桌面图标」切回「桌面插件」。
  • 点不出来 / 点别处不消失？ 只有挂件条小方框内响应鼠标，方框外故意穿透。
  • 拖动松手飞了 / 卡半空？ 受屏幕工作区限制属正常；异常时重启即恢复默认落点。
  • 节假日数据准吗？ 为 2026 年国务院安排（硬编码），每年需更新一次。
  • 怎么不开机自启？ 右键菜单取消「开机自启」勾选。
