简洁桌面日历 · 使用说明

极简 Windows 桌面日历　v1.0.0　作者：YG

什么功能都没有，核心只做一件事——看日历、看放假、看上班。下面是它的全部用法。

一、它在哪里

安装后，右下角任务栏（通知区）会出现一个实时时钟图标（显示 时:分 与 月-日）。这就是它的入口，常驻后台、不占任务栏按钮。

  • 点击托盘时钟 → 打开 / 隐藏日历窗口
  • 鼠标悬停托盘时钟 → 显示「农历 + 星期」
  • 点击日历界面外的任意位置 → 日历自动隐藏

二、看日历

  • 顶部大字是当前时间，右侧是公历日期与农历。
  • 日历区每天下方的小字是农历 / 节气 / 节日。
  • 左上 ‹ › 翻月；下拉框可直接选年/月；点 今 回到本月。
  • 今日以雅蓝描边高亮，和「选中」同一效果。

三、看放假 / 看上班

  • 法定节假日：朱砂红底 + 右上角红色 休 角标。
  • 调休补班日：右上角蓝色 班 角标（仅当月显示）。
  • 周末数字默认偏砖红，方便区分。
节假日数据按 2026 年国务院办公厅安排内置。跨年的放假/补班安排出来后，软件需更新对应数据（见 README「已知限制」）。

四、按你的习惯调

  • 每周起始：右上「一 / 日」开关，切换周一或周日为每周第一天。
  • 主题：点右上 ☾ 按钮，在「默认雅蓝」与「跟随 Windows 强调色」之间切换。
  • 放大：点右上 ⊕，窗口放大到近全屏、字号同步放大；拖动到屏幕边缘会自动吸附；点别处退出放大。

五、开关机与卸载

  • 默认开机自启，登录后托盘自动出现时钟。
  • 右键托盘时钟 → 「退出」可彻底关闭进程。
  • 卸载：控制面板 → 程序和功能 → 简洁桌面日历；或开始菜单文件夹内的「卸载」。会清理安装目录、桌面与开始菜单快捷方式及注册表项。
