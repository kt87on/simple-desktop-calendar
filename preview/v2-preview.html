本预览演示的交互：
1. 任务栏部件替换原生时钟（上时间/下日期，随主题切黑/白字）
2. 悬停部件 → 显示农历+星期；右键部件 → 打开 / 退出 菜单
3. 点「退出」→ 恢复原生时间日历
4. 日历窗口放大 → 上方贴顶、下方贴任务栏、等比放大；右上角 ✕ 点击弹「是否退出软件」确认框
5. 点一个日期变绿，再点另一个 → 两格变绿且中间浮现共计 N 天；点窗口任意处/窗外取消
（真实任务栏替换/右键拦截需在正式版 Windows 上验证）
